# 📝 Next.js + TypeScript TodoList

Next.js와 TypeScript, Jest를 기반으로 구현한 TodoList 예제 프로젝트입니다.
테스트 및 여러 코드 연습용

### 기술 스택

- Next.js 15 (App Router)
- TypeScript
- Zustand (상태 관리)
- TanStack Query (서버 상태)
- Jest + Testing Library (테스트)
- Storybook 8 (컴포넌트 문서화)

---

## 🚀 설치 및 실행

### 1. 프로젝트 설치

```bash
git clone https://github.com/your-username/todolist.git
cd todolist
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

➡️ 브라우저에서 [http://localhost:3000](http://localhost:3000) 접속

## 🧪 테스트 실행
